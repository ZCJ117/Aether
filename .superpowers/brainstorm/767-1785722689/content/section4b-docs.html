快速开始

5 分钟启动第一个 Aether Agent

环境要求

  • JDK 17+
  • Maven 3.8+
  • Node.js 18+ (前端开发)

克隆与构建

git clone https://github.com/your-org/aether.git
cd aether
mvn clean install -DskipTests
cd aether-app && mvn spring-boot:run

最小配置模板

在 aether-app/src/main/resources/agent/ 下创建 YAML 配置文件：

ai-api:
  base-url: https://api.openai.com
  api-key: ${OPENAI_API_KEY}
chat-model:
  model: gpt-4o
agents:
  - name: assistant
    system-prompt: 你是一个有用的助手。
runner:
  agent-name: assistant

验证运行

curl -X POST http://localhost:8080/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello Aether!"}'
