设计段 1/5 — 导航栏组件 (LandingNavbar.vue)

基于 MateClaw 交互模式，适配 Aether 现有技术栈 (Vue 3 + TailwindCSS + @vueuse/motion)

组件结构

<template>
  <header class="fixed top-0 left-0 right-0 z-50 transition-all duration-300"
          :class="{ 'bg-black/70 backdrop-blur-xl border-b border-white/10': scrolled }">
    <div class="nav-inner flex items-center justify-between px-6 md:px-10 h-16">

      <!-- Logo -->
      <a href="#" class="flex items-center gap-3 group">
        <AetherLogo className="w-8 h-8" />
        <span class="font-black text-lg text-white">Aether</span>
      </a>

      <!-- Desktop Nav -->
      <nav class="hidden md:flex items-center gap-1">
        <a v-for="item in NAV_ITEMS" :key="item.label"
           :href="item.href"
           @click="handleNavClick(item, $event)"
           class="nav-link text-sm font-medium px-3.5 py-2 rounded-lg
                  transition-all duration-200"
           :class="{ 'text-white bg-white/10': isActive(item),
                    'text-white/60 hover:text-white hover:bg-white/5': !isActive(item) }">
          {{ item.label }}
        </a>
      </nav>

      <!-- Right: GitHub + CTA -->
      <div class="flex items-center gap-2">
        <a href="https://github.com/..." target="_blank" class="w-9 h-9 ...">
          <!-- GitHub icon -->
        </a>
        <LandingButton label="开始使用" @click="emit('cta')" />

        <!-- Mobile hamburger -->
        <button @click="mobileOpen = !mobileOpen" class="md:hidden ...">
          <Menu />
        </button>
      </div>
    </div>

    <!-- Mobile dropdown -->
    <Transition name="slide-down">
      <div v-if="mobileOpen" class="md:hidden border-t border-white/10 bg-black/90 ...">
        <a v-for="item in NAV_ITEMS" ...>{{ item.label }}</a>
      </div>
    </Transition>
  </header>
</template>

关键交互细节

交互 实现方式
固定定位 fixed top-0 z-50，始终在最上层
滚动背景过渡 window.scrollY > 0 → 添加毛玻璃背景 + 底部边框；CSS transition-all duration-300
当前项高亮 锚点项：监听 scroll 位置判断当前 section；路由项：匹配 route.path
移动端折叠 mobileOpen ref + md:hidden 汉堡按钮 + slide-down Transition
导航项悬停 text-white/60 hover:text-white hover:bg-white/5 + rounded-lg

NAV_ITEMS 数据结构

const NAV_ITEMS = [
  { label: '亮点',     href: '#highlights',   type: 'anchor' },
  { label: '架构',     href: '#architecture',  type: 'anchor' },
  { label: '产品预览', href: '#preview',       type: 'anchor' },
  { label: '路线图',   href: '/roadmap',       type: 'route' },
  { label: '文档',     href: '/docs',          type: 'external' },
]

type 决定点击行为：anchor → smooth scroll；route → router.push；external → window.open(_blank)
